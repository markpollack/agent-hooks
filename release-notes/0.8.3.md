# Agent Hooks 0.8.3

Maintenance release moving the Claude adapter to **Claude Agent SDK 1.7.0**, the SDK release the AgentWorks
BOM 1.21.0 manages.

## What changed

- `claude-code-sdk` 1.5.1 → 1.7.0 for `agent-hooks-claude` (`provided` scope — consumers supply the SDK).
  1.7.0 destroys the CLI process tree before closing its streams, so closing or cancelling a session no longer
  hangs or leaves the CLI running.

No source change and no API change. All 105 tests pass against 1.7.0.

## Upgrading

Drop-in. Bump the `agent-hooks` coordinates to 0.8.3 and supply `claude-code-sdk` 1.7.0 (the AgentWorks BOM
1.21.0 manages both).

## Maven Central

`io.github.markpollack` version `0.8.3`: `agent-hooks-parent`, `agent-hooks-core`, `agent-hooks-spring`,
`agent-hooks-gemini`, `agent-hooks-claude`. Each carries its consumer-rooted CycloneDX SBOM
(`-cyclonedx.json`) as a signed attachment.
