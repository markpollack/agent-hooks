# Agent Hooks 1.0.0

Agent Hooks 1.0.0 is part of AgentWorks BOM 1.22.0. It moves the Claude adapter to **Claude Agent SDK 1.8.0** and
raises Jackson past the jackson-core and jackson-databind CVEs (CVSS 7.5).

## What changed

- **Jackson:** 2.22.2 → 2.22.3 and 3.2.2 → 3.2.3 (`8d542f0`). These fix CVE-2026-89407 and CVE-2026-89425 in
  jackson-core and CVE-2026-91776 and CVE-2026-91777 in jackson-databind. `agent-hooks-gemini` depends on
  `jackson-databind` at compile scope, so its consumers get the fixed version. `agent-hooks-claude` declares
  Jackson as `provided`.
- **Claude Agent SDK:** `claude-code-sdk` 1.7.0 → 1.8.0 for `agent-hooks-claude`, at `provided` scope as before,
  so you supply the SDK yourself. SDK 1.8.0 now sends each hook callback's `HookOutput` in the nested
  `hookSpecificOutput` form the CLI reads. SDK 1.7.0 flattened it instead. With 1.8.0, the decisions
  `AgentHookBridge` returns from a PreToolUse hook reach the CLI as built:
  - a `Block` is sent as `permissionDecision: deny` with its reason;
  - a `Modify` is sent as `updatedInput`.
- **Licence:** the BSL 1.1 text matches the canonical licence (`0f30c1e`). The terms are unchanged.

There is no change to the Agent Hooks source or API. All 105 tests pass against SDK 1.8.0.

## Upgrading

The upgrade is drop-in. Bump the `agent-hooks` coordinates to 1.0.0 and supply `claude-code-sdk` 1.8.0. The
AgentWorks BOM 1.22.0 manages both.
