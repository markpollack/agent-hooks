## Agent Hooks 0.8.0

This maintenance release refreshes Agent Hooks to Claude Agent SDK 1.5.0 and current compatible
stable Spring AI, Spring Boot, Jackson, test, SBOM, and release-tooling versions.

All four published modules continue to resolve exclusively from Maven Central. The core, Spring,
and Gemini modules retain their Java 17 baseline; the Claude adapter retains Java 21 because the
provided Claude SDK is Java 21 bytecode.
